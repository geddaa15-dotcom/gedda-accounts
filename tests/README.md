# اختبارات الحسابات

```
node tests/run.js --changed   # الطريقة العادية قبل الرفع: بيشغّل اللي يخص الملفات اللي اتغيرت بس
node tests/run.js             # كله (حوالي دقيقتين)
node tests/run.js --only=acc  # الحسابات من غير قسم الفتح السريع (حوالي دقيقة ونص)
node tests/run.js --only=smoke  # كل الصفحات بتفتح من غير أخطاء (لتعديلات الشكل بس)
node tests/speed.js           # السرعة: حسابات كبيرة على معالج أبطأ 4 مرات
node tests/shots.js <فولدر>   # صور كل الشاشات ببيانات تجريبية ثابتة (--list للأسامي، --only=اسم,اسم)
```

بيشغّل الموقع على الجهاز، ويفتحه في متصفح من غير شاشة، ويجرب بيانات تجريبية (مفيهاش أي عميل حقيقي):
كلمة السر والتشفير، نقل الإكسيل، الفواتير والدفعات والمرتجعات والخصم، الخزنة والجرد، الشركاء، عروض الأسعار،
الاسم على كل حركة وصفحة "اللي اتعمل"، كشف الحساب PDF، التقارير، قفل الشهر، المزامنة مع شيت Google على أكتر من جهاز،
النسخ الاحتياطية (فولدر اللاب وسطر Drive)، والفتح السريع بنت مقطوع أو بطيء (`sw.js` + `lib/swup.js`، قسم ٢٣).

كل اختبار بيقارن الأرقام بالقرش. لازم يطلع في الآخر "0 فشل" قبل رفع أي تعديل. في الآخر بيطبع وقت كل قسم.
`gasmock.js` بيقلّد Google Apps Script علشان نجرب كود الشيت من غير نت. `fixtures/acc-sheet-v*.gs` = نسخ كود الشيت القديمة علشان نتأكد إن الجديد لسه بيفهمها.

## إزاي `--changed` بيختار

| اللي اتغير | بيشغّل |
|---|---|
| `accounts.html` جوه الـ `<style>` بس | smoke |
| أي حتة تانية في `accounts.html` | كله |
| `lib/` أو `sw.js` أو `fonts/` أو ملفات الاختبار نفسها | كله |
| أي صفحة تانية أو `icons/` | smoke |
| ملفات كلام بس (`.md`) | ولا حاجة |

قسم ٢٣ (الفتح السريع والنت البطيء، ~30 ثانية) في `--changed` بيشتغل بس لو `sw.js` أو `lib/swup.js` أو `tests/run.js` اتغيروا. التشغيل الكامل (وGitHub بعد الرفع) بيشغّله دايماً.

## الانتظار الذكي (`settle`)

`X.settle(300)` بيستنى لحد ما كل الصفحات المفتوحة تخلص شغلها (المؤقتات القصيرة، طلبات الشيت، التشفير، IndexedDB) وبعدها 60 ملّي هدوء. الرقم المكتوب هو **أقصى** انتظار.

- **مؤقتات 1.5 ثانية أو أكتر مش بتتستنى** (المزامنة بعد الحفظ `schedSync`). اختبار محتاج نتيجتها يستناها بـ `waitForFunction`.
- `SETTLE_DEBUG=1 node tests/run.js` بيطبع أكتر الانتظارات اللي وصلت للحد الأقصى ومين السبب.
- **متستخدمش `waitForTimeout`** في أي اختبار جديد. استخدم `settle` أو `waitForSelector`/`waitForFunction`.
